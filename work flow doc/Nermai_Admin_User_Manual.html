Module 1

📝 Test Portal Administration

The Test Portal manages computerized mock exams, offline test mark registers, AI-driven question paper digitization, anti-cheat proctored examination monitoring, real-time leaderboards, and candidate performance analytics.

1.1 Available & Active Exams Dashboard
Sidebar ➔ Test Portal ➔ Available Exams (`testSub === "available"`)

This is the central examination command center. Admins can view all scheduled, live, and past examinations, monitor live attempts in real-time, toggle publish status, and adjust roll-number permissions.

CRUD Action Trigger & Button in UI System Workflow & Result
READ Test Directory Grid Displays list of tests with title, target course/batch, question count, duration (mins), total marks, and current status (Draft, Scheduled, Active, Ended). Filter by Active, Upcoming, Offline, or Completed.
UPDATE Edit Test (`Edit` Icon) Opens modal to update Test Name, Instructions, Duration, Negative Marks per wrong answer, Target Batches, Pass Mark %, and Subject Section Configurator.
UPDATE Publish / Unpublish Toggle Immediately toggles visibility of the exam to students in the mobile app and web portal. Unpublishing locks student entry instantly.
READ Live Exam Proctor Monitor Opens the real-time proctor dashboard showing: (1) Active live test-taker count, (2) Real-time leaderboard with auto-refreshing scores, (3) Anti-cheat tab-switching / window blur security alerts, and (4) Absentee student roster.
UPDATE Offline Permission Requests Review pending permission requests submitted by students who missed the exam deadline or need offline retakes. Click Approve or Reject with 1-click status update.
DELETE Delete Test (`Trash` Icon) Triggers confirmation modal. Performs soft-delete (`isActive: false`), removing the test from student views while archiving exam results in the database.
💡 Admin Pro-Tip: Special Mock Roll Number Configurator
For statewide scholarship exams or public mock tests, Admins can click "Mock Roll Config" to generate serialized candidate roll numbers (e.g., NERMAI-MOCK-001) and automatically sync them to unassigned applicants.
1.2 AI Question Paper Extraction & Manual Creator
Sidebar ➔ Test Portal ➔ Create Test (`testSub === "pdf-create"`)

Create new exams using either the automated AI extraction engine (which parses PDF/Word documents) or manual question-by-question authoring.

CRUD Action Trigger & Button in UI System Workflow & Result
CREATE Upload PDF / Word Document Admin selects Question Paper PDF and optional Answer Key PDF/CSV. Clicking Extract with AI forwards the document to Groq Llama-3.3-70b / Gemini 1.5 Flash. The AI extracts questions, bilingual translations (English & Tamil), 4 options, correct keys, and explanations into a structured JSON draft.
CREATE Manual Add Question (`+ Add`) Inserts an empty question card into the test builder. Admin fills: Question text (English/Tamil), Options A/B/C/D, Correct Option selector, Explanation text, and Marks weightage.
UPDATE Upload Diagram / Question Image Uploads question illustrations or charts to the secure Google Drive backend; binds the returned image URL directly to Question #N.
UPDATE Subject Section Splitter Groups questions into distinct exam sections (e.g., Section A: History [Q1-25], Section B: Polity [Q26-50], Section C: Aptitude [Q51-100]) with individual section timers and negative mark rules.
CREATE / UPDATE Save Draft / Publish Immediately Writes test document to Firestore under tests collection. If marked published, it activates immediate push notifications to eligible batch students.
1.3 Exam Results, Evaluation & Offline Excel Upload
Sidebar ➔ Test Portal ➔ Results (`testSub === "results"`)

Review candidate attempts, upload OMR/offline test scores via Excel, re-evaluate marks upon question disputes, and export official rank lists.

CRUD Action Trigger & Button in UI System Workflow & Result
READ Candidate Results Table Displays Rank, Student Name, Roll Number, Correct Count, Wrong Count, Skipped Count, Total Marks Obtained, Percentage %, and Time Taken.
CREATE Upload Offline Results Excel Click "Upload Offline Excel". Admin uploads populated spreadsheet (`Sample_Offline_Results.xlsx`). System matches candidates by Roll Number, calculates scores, and merges offline marks directly into student ERP marksheets.
UPDATE Recalculate Results (`Recalculate`) If an answer key error is corrected in a test, clicking Recalculate triggers background re-scoring across all student attempts, automatically refreshing ranks and percentile scores.
READ Export Results (Excel / PDF) Downloads formatted Excel marksheet with question-level diagnostic data, topic accuracy breakdown, and statewide ranks.
DELETE Reset / Delete Attempt (`Delete Result`) Super-Admin action to remove a glitchy or incomplete student attempt, allowing the student to re-take the exam under supervision.
1.4 Question Dispute & Student Feedback Desk
Sidebar ➔ Test Portal ➔ Test Feedback (`testSub === "feedback"`)

Track questions reported by students due to ambiguous wording, translation mismatches, or disputed answer keys.

CRUD Action Trigger & Button in UI System Workflow & Result
READ Dispute Feed Lists Test Name, Question ID, Student Name, Roll No, Disputed Reason, and Student Remarks/Proof.
UPDATE Resolve & Update Key Admin can correct the question option or award full bonus marks for that question, then click Mark Resolved.
DELETE Dismiss Report Archives invalid or baseless dispute tickets.
Module 2

🏛️ Enterprise Resource Planning (ERP)

The ERP Module controls institutional student directories, multi-tier fee ledgers, batch allocations, staff profiles, biometric & offline QR attendance, student profile change requests, digital ID cards, and exam hall tickets.

2.1 Student Management Directory & Bulk Onboarding
Sidebar ➔ ERP ➔ Students (`erpSub === "students"`)

Complete lifecycle management of all academy candidates across Offline, Online, and Recorded batches.

CRUD Action Trigger & Button in UI System Workflow & Result
CREATE Add Student (`+ Add Student`) Opens multi-step modal:
• Step 1 (Credentials): Username, Password, Role.
• Step 2 (Academics): Course (UPSC, TNPSC, Banking, etc.), Batch selection, Mode (Offline / Online / Recorded), Roll No, Admission No.
• Step 3 (Personal): Name, Phone, Email, DOB, Gender, Parent/Guardian details, Address, Photo ID document upload.
• Step 4 (Finance): Total Course Fee, Initial Amount Paid, Payment Mode (Cash, UPI, Bank Transfer), Transaction ID.
CREATE Bulk Upload Excel (`Bulk Upload`) Download standard template (Sample_Bulk_Students_Template.xlsx). Upload populated sheet. Validates phone numbers, duplicates, and batch allocation, creating hundreds of accounts in a single batch.
READ Student Profile & Filters Search by Name, Roll No, Phone, or Admission No. Filter by Course, Batch, Study Mode, or Fee Clearance status. Click student row to open 360° Academic Ledger.
UPDATE Edit Student Profile (`Edit`) Update any personal detail, change batch allocation, reset password, update contact info, or upload updated passport photo.
UPDATE Device Lock Reset (`Reset Device`) Clears student hardware fingerprint lock when a student changes their smartphone or laptop, allowing them to log in on their new device.
DELETE Deactivate / Delete (`Delete`) Soft delete candidate record (`status: inactive`), locking portal access while preserving historical marks and payment records for auditing.
2.2 Fee Management, Invoicing & Due Collection
Sidebar ➔ ERP ➔ Fees (`erpSub === "fees"`)

Track total academy revenue, student installments, pending balances, fee defaulters, and issue official stamped PDF fee receipts.

CRUD Action Trigger & Button in UI System Workflow & Result
READ Financial Summary & Ledger Shows metric cards: Total Expected Revenue, Total Collected, Pending Dues, and Defaulter count. Table lists Student Name, Roll No, Total Fee, Amount Paid, Remaining Balance, and Payment Status (Paid, Partial, Unpaid).
CREATE Record Payment (`+ Collect Fee`) Modal form: Select Student, Enter Amount Paid, Select Payment Mode (Cash, GPay/PhonePe, Bank NEFT, Cheque), Enter Bank Ref/Transaction ID, Date of Payment, and Notes.
READ Generate Fee Receipt (PDF) Generates instant printable/downloadable official payment receipt containing academy header, student roll no, GSTIN, amount breakdown, balance remaining, and digital stamp.
UPDATE Fee Reminder & Portal Lock Click Send Fee Reminder to dispatch SMS/Push alert. Admin can toggle Portal Access Lock to restrict LMS/Test portal access until overdue installments are settled.
2.3 Batch Scheduling & Faculty Management
Sidebar ➔ ERP ➔ Batches (`erpSub === "batch"`) & Staff (`erpSub === "staff"`)

Configure academy classrooms, schedule batches across morning/evening/weekend timings, and manage faculty subject allotments.

CRUD Action Trigger & Button in UI System Workflow & Result
CREATE Create Batch (`+ New Batch`) Input Batch Name (e.g. TNPSC Group 1 Morning 2026), Course, Max Student Capacity, Start Date, End Date, Timings (09:00 AM - 01:00 PM), and Venue/Classroom.
UPDATE Batch Reallocation Transfer students from one batch to another in bulk (e.g., from Weekday to Weekend batch).
CREATE / UPDATE Staff Directory (`+ Add Faculty`) Create faculty profile with Name, Email, Mobile, Subject Specialization (e.g., Indian Economy, Current Affairs), and assign them to specific Course Batches.
DELETE Archive Batch / Deactivate Staff Closes finished batches and removes staff credentials without impacting past recorded classes.
2.5 Offline Attendance & Barcode/QR Scanner
Sidebar ➔ ERP ➔ Offline Attendance (`erpSub === "offline-attendance"`)

Track daily physical classroom attendance using webcam/handheld QR scanners or manual roster grids.

CRUD Action Trigger & Button in UI System Workflow & Result
CREATE / UPDATE QR / Barcode Scanner Activate camera scanner. As students scan their physical ID card or mobile app QR code at the academy reception, system marks them Present with timestamp.
UPDATE Manual Roster Toggle Select Course & Batch. Grid lists all students. Click status badge to toggle between Present, Absent, Late, or Excused.
READ Export Monthly Attendance (Excel) Downloads complete monthly attendance sheet with percentage calculations and absentee flags.
2.6 Profile Requests, ID Cards & Hall Tickets
Sidebar ➔ ERP ➔ Profile Requests & ID Cards

Review student profile change requests, design digital student ID cards, and issue examination hall tickets.

CRUD Action Trigger & Button in UI System Workflow & Result
READ Profile Request Review Queue Lists pending student requests comparing Old Value vs. Requested New Value (e.g., name spelling, phone number change, address).
UPDATE Approve / Reject Request Clicking Approve writes changes directly to the student profile. Clicking Reject prompts for a reason sent to the student.
CREATE / READ Generate ID Card (`Generate ID`) Generates printable credit-card style identity badge with student photo, barcode/QR code, roll number, course, blood group, and emergency contact.
CREATE / READ Generate Hall Ticket (`Issue Hall Ticket`) Populates exam venue, date, seating instructions, and student signature box. Exportable as PDF.
Module 3

📚 Learning Management System (LMS)

The LMS delivers the academic core: a 4-tier structured syllabus hierarchy, daily current affairs publishing, digital study material repositories with DRM protection, Zoom/YouTube interactive live classes, watermarked video lectures, and syllabus progress tracking.

3.1 4-Tier Academic Hierarchy (Courses ➔ Subjects ➔ Topics ➔ Subtopics)
Sidebar ➔ LMS ➔ Courses, Subjects, Topics, Subtopics

Build the academic syllabus structure into four nested levels to organize all study materials, videos, and quizzes.

CRUD Action Hierarchy Level & UI Button System Workflow & Result
CREATE / UPDATE / DELETE Level 1: Courses (`+ New Course`) Create main course program (e.g. UPSC Civil Services Examination). Set course code, thumbnail banner, target exam date, and assign course director.
CREATE / UPDATE / DELETE Level 2: Subjects (`+ New Subject`) Link subject under Course (e.g. Indian Polity & Constitution, Modern Indian History). Reorder subjects, edit syllabus codes.
CREATE / UPDATE / DELETE Level 3: Topics (`+ New Topic`) Link topic under Subject (e.g. Fundamental Rights, Judiciary & Supreme Court). Assign estimated lecture hours.
CREATE / UPDATE / DELETE Level 4: Subtopics (`+ New Subtopic`) Sub-chapter level (e.g. Article 21: Right to Life & Privacy). Directly attach video classes, PDF handouts, and revision quizzes here.
3.2 Daily Content, Editorials & Current Affairs Desk
Sidebar ➔ LMS ➔ Daily Content (`lmsSub === "daily-content"`)

Publish daily study schedules, Hindu editorial summaries, PIB press releases, and current affairs capsules for students.

CRUD Action Trigger & Button in UI System Workflow & Result
CREATE Post Daily Content (`+ Add Content`) Modal form: Select Date (defaults to today), Category (Daily News Analysis, Editorial, TNPSC Capsule, PIB Brief), Article Title, Body content (Rich Text / Markdown), and Attachment upload (PDF notes or infographic).
READ Daily Content Calendar View Browse daily posts by calendar date. Filter by category or search by topic keywords. View student read-receipt counters.
UPDATE Edit Content (`Edit`) Update article text, replace PDF documents, or correct typos in published news capsules.
DELETE Delete Content (`Trash`) Removes the post from student daily feeds and deletes files from Google Drive storage.
3.3 Digital Resources Library & Audio Narration
Sidebar ➔ LMS ➔ Resources (`lmsSub === "resources"`)

Host academy reference books, NCERT summaries, previous year question compilations, and synced audio revision tracks.

CRUD Action Trigger & Button in UI System Workflow & Result
CREATE Upload Resource (`+ Upload`) Select Target Course & Subject. Enter Document Title, Document Type (Standard Text, Formula Sheet, Mindmap), upload primary PDF file (up to 150MB), and optional MP3 Audio Track for audio-guided study.
READ Hierarchy Folder Browser Browse files by Course ➔ Subject ➔ Topic. Includes built-in secure PDF viewer preview and audio player.
UPDATE Version Upload (`Upload New Version`) Replaces PDF file while keeping identical resource ID, preventing broken bookmarks for students.
UPDATE Access Rules & Watermark Settings Lock resource to specific paid batches or enable public preview for guests. Toggle DRM dynamic student watermark on PDF pages.
DELETE Delete Resource (`Trash`) Permanently deletes resource file and associated audio narration from cloud storage.
3.4 Interactive Live Sessions & Recorded Video Classes
Sidebar ➔ LMS ➔ Live Classes (`lmsSub === "live-classes"`) & Recorded (`lmsSub === "recorded"`)

Schedule real-time Zoom/YouTube classrooms with anti-piracy features and maintain a searchable library of recorded lectures.

CRUD Action Trigger & Button in UI System Workflow & Result
CREATE Schedule Live Session (`+ Schedule`) Enter Session Title, Subject, Topic, Host Faculty, Date, Start Time, Duration. Select Provider: Zoom Meeting SDK or YouTube Live. Choose Zoom Account from the multi-account pool. Target specific Batches.
UPDATE Live Host Command Controls During live session: (1) Start Attendance Polling (verifies student presence via heartbeat), (2) Live Chat Moderation (mute/kick unruly students, block globally), (3) Extend Session by 15/30 mins.
UPDATE End Session & Convert to Recording Clicking "End with Conversion" automatically pulls Zoom cloud recording and publishes it into the LMS Recorded Lectures library under the matching Topic!
CREATE / UPDATE Manual Recorded Video Upload Upload or embed past lecture video (Google Drive stream, Cloudinary, YouTube unlisted). Set dynamic floating watermark (Student Name + Phone + IP) to deter screen recording.
DELETE Cancel Live / Delete Recording Cancel upcoming live class (notifies students via push alert) or delete obsolete lecture videos.
3.6 Syllabus Tracker & Excel Importer
Sidebar ➔ LMS ➔ Syllabus Tracker (`lmsSub === "lms-syllabus"`)

Monitor curriculum coverage percentages per batch and bulk-import full syllabus hierarchies from Excel.

CRUD Action Trigger & Button in UI System Workflow & Result
CREATE Bulk Excel Syllabus Import Upload multi-column syllabus sheet (Columns: Course, Subject, Topic, Subtopic, Hours). Auto-populates complete LMS tree without manual clicking.
READ / UPDATE Track Completion Percentage Displays progress bars: Completed hours vs. Total syllabus hours. Faculty marks topics Covered upon class completion.
Module 4

🤝 Customer Relationship Management (CRM)

The CRM drives student enrollment pipelines: managing inbound course inquiries, processing online admissions from the public website, running targeted push broadcast campaigns, updating homepage guest promotional banners, and building custom inquiry forms.

4.1 Lead Intake Pipeline & 1-Click ERP Conversion
Sidebar ➔ CRM ➔ Leads (`crmSub === "leads"`)

Manage all prospective student inquiries arriving via website forms, Google Sign-in guest attempts, telephone calls, or social media ads.

CRUD Action Trigger & Button in UI System Workflow & Result
CREATE Add Walk-in Lead (`+ Add Lead`) Enter Candidate Full Name, Mobile Phone, Email, City, Target Course of interest, Preferred Study Mode (Offline/Online), and Lead Source (Walk-in, Phone Inquiry, Instagram, Reference).
READ Lead Pipeline & Status Filter Table displays leads categorized by stage: New, Contacted, Counseling Scheduled, Follow-Up Needed, Interested, Converted, Dropped.
UPDATE Update Lead Status & Counselor Notes Click lead row to log counselor notes, schedule next callback date/time, and update lead interest temperature (Cold, Warm, Hot).
UPDATE Convert to Student (`Convert to Student`) The golden bridge between CRM and ERP! Clicking Convert to Student automatically transfers candidate details into the ERP Student Registration modal, creates their student account, and generates their unique Roll Number.
DELETE Archive / Delete Lead (`Delete`) Purges duplicate or spam inquiries.
4.2 Online Admission Form Processing
Sidebar ➔ CRM ➔ Admissions (`crmSub === "admissions"`)

Review comprehensive admission application forms submitted by visitors through the public website's "Apply Now" portal.

CRUD Action Trigger & Button in UI System Workflow & Result
READ Admission Application Cards Displays applicant's Full Name, Course Selected, Educational Qualifications, Father's Name, Permanent Address, Photo ID proof, and application timestamp. Filter by Pending, Under Verification, or Approved.
UPDATE Direct Enroll (`Enroll Student`) Assigns batch, approves application, provisions login credentials, and sends welcome SMS/Email with portal access details.
DELETE Reject Application (`Reject`) Rejects application with custom rejection remarks sent to the applicant.
4.3 Marketing Campaigns & Targeted Push Notifications
Sidebar ➔ CRM ➔ Campaigns (`crmSub === "campaigns"`)

Broadcast high-converting push notifications, exam announcements, and promotional popups to targeted user cohorts.

CRUD Action Trigger & Button in UI System Workflow & Result
CREATE Create Campaign (`+ New Campaign`) Modal form: Campaign Name, Notification Title, Body text, Optional Banner Image URL. Target Audience selector: (1) All Registered Users, (2) Free / Guest Leads Only (for enrollment upsell), or (3) Paid Students Only. Set Deep-Link action (e.g., opens specific Free Mock Test or Admission Page).
READ Campaign Performance Metrics View sent campaigns, dispatch timestamps, total recipients, delivery success rates, and student click-through percentages.
DELETE Delete Campaign (`Trash`) Stops scheduled future recurring blasts and archives campaign logs.
4.4 Guest Promotional Posters & Custom Lead Forms
Sidebar ➔ CRM ➔ Guest Posters (`crmSub === "guest-posters"`) & Custom Forms

Control the public landing page hero banner slider and build dynamic survey/scholarship inquiry forms.

CRUD Action Trigger & Button in UI System Workflow & Result
CREATE Upload Guest Banner (`+ Upload Poster`) Upload high-resolution promotional poster graphic (1920x1080). Enter Poster Title, Call-to-Action (CTA) label (e.g., "Apply for UPSC 2026 Batch"), and redirect target URL.
READ Poster Gallery & Live Preview Displays all active banners currently rotating on the public landing page. Reorder banners to change slide sequence.
UPDATE Toggle Active Banner Turn individual banners ON or OFF with a single toggle switch without deleting the artwork.
DELETE Delete Poster (`Trash`) Removes outdated banners from the website hero carousel immediately.
CREATE / READ Custom Lead Forms Builder Build custom registration forms with custom questions (e.g. "Which optional subject have you chosen?", "Are you preparing full-time or working?") and export submissions directly to Excel.
